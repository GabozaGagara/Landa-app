Позиции просчёта

Источник: только лист «Подсчет» файла LANDA-Corporation(1).xlsx. Основные строки (5–287) включены в итог, дополнительные показатели и сверка — отдельно. 🔐 Персональные коды поставщиков

Создай три случайных кода и вставь весь JSON в секрет Cloudflare SUPPLIER_CODES. Коды не сохраняются на этом сайте: сохрани их в менеджере паролей, затем передай каждому поставщику только его код.

Не публикуй эти коды. Если нажмёшь «Создать» ещё раз, прежние коды перестанут подходить после изменения секрета в Cloudflare.

Если сервер запущен, каждая ссылка откроет форму с кнопкой «Отправить прямо в LANDA». Для записи нужен личный код поставщика. Коды, GitHub-токены и финансовую базу поставщикам не передавать.
СДЭК · личный кабинет физлица

Кнопка «Обновить статусы» собирает все невручённые отправления из Бреста. Проверь статусы на сайте СДЭК или через ChatGPT Work, затем подтверди пакетное обновление в LANDA. Вход по номеру телефона и SMS остаётся только на стороне СДЭК.

↗ Мои посылки / отслеживание ↗ Официальный API СДЭК
Автоматическая загрузка накладных из обычного кабинета физлица пока не подключена: по данным СДЭК, официальный API выдаётся отдельно для договорного обслуживания. Подключение API не заменяет авторизацию физлица. Не вводи пароль или SMS-код от СДЭК в LANDA.
Накладные можно импортировать из CSV (только «Брест»), а стоимость товара и доставки в $ вносится вручную (можно вставлять список товаров из выгрузки). Прямой синхронизации с «МойСклад» и СДЭК пока нет. Новые накладные не увеличивают долг автоматически. При статусе «Вручен» проверьте суммы и нажмите «Начислить поставщику».
Начальный баланс поставщика
Минус — вы уже должны поставщику, будет создана отдельная учетная строка «Начальный долг». Плюс — у него лежит ваш аванс; его можно будет зачесть в новые накладные. Касса не меняется.
Не добавляйте начальный долг, если вы уже занесли те же старые накладные, иначе задолженность удвоится.
Поступление или расход
Запишите поступление от клиента на выбранный счёт. Для Авито укажите ожидаемую чистую выплату и номер заказа в комментарии. Перемещение денег между собственными счетами делайте кнопкой «Между счетами», чтобы не удваивать выручку. Оплата поставщикам — только в их разделе.
Перевод между своими счетами
Выберите счета и сумму.
Перевод не является новой выручкой. Он одновременно уменьшает один рублёвый баланс и увеличивает другой. Авито Доставка → Карты означает фактическую выплату от Авито. Переводы в Авито не предусмотрены.
Покупка долларов за рубли
Укажите количество долларов и курс.
Создаются две связанные записи: расход рублей с выбранного счёта и приход наличных долларов. Удаляются только вместе.
Курс ранее внесённых долларов
Укажите реальный курс, по которому получили доллары.
Начальные остатки по счетам
Начальные остатки — деньги и ожидаемые выплаты до первой операции в журнале. Не вводите здесь сумму, уже отражённую поступлениями, иначе деньги будут посчитаны дважды.
Новая накладная
Доставка всегда входит в общую стоимость накладной и в сумму долга после начисления. Она также показывается отдельно.
Укажите товары или сумму.
Новая накладная сначала ожидает подтверждения. После статуса «Вручен» нажмите «Начислить поставщику»: долг включает товары и доставку. Уже начисленные исторические накладные не пересчитываются автоматически.
Принять накладную от поставщика
Безопасный импорт: вставьте JSON, присланный поставщиком, или выберите файл LANDA-*.json. Программа проверит маршрут из Бреста, поставщика, товары, суммы и дубликаты. Приём не начисляет долг и не подтверждает вручение.
Выберите файл или вставьте JSON для проверки.

Подтвердите действие
Позиция
Сумма участвует в общем итоге, если строка находится в одном из основных разделов.
Новый расчёт
Будут скопированы остатки рабочих строк выбранного периода. Доходы/расходы и контрольные показатели прошлого периода не переносятся. После создания измените нужные суммы — итог пересчитается сам.

☁ Синхронизация с GitHub
iPhone: для синхронизации открой сайт LANDA по HTTPS в Safari. Встроенный просмотрщик HTML (в ChatGPT, «Файлах» и мессенджерах) может блокировать запросы GitHub и показывать «Load failed».
После подключения LANDA будет хранить данные и локально, и в приватном репозитории GitHub. При каждом новом запуске проверяется облачная версия. После изменения программы запись отправляется автоматически с небольшой задержкой. Нужен интернет.
Подключение GitHub не всегда означает, что облачная база уже открыта. Если просчёт пустой, нажми «Загрузить финансовые данные из GitHub». Программа покажет количество строк и периодов до замены локальных данных; облачная копия останется неизменной.

Локальные и облачные данные различаются

Для защиты учёта автоматическая замена отключена. Выбери нужную версию.

Безопасность: используй только приватный репозиторий. Данные в нём хранятся обычным JSON, без шифрования. Токен не входит в резервные копии и не записывается внутрь HTML. Не отправляй токен в чат. Для постоянной работы после закрытия браузера потребуется включить «Запомнить токен».
Если видишь ошибку 404: название репозитория может быть правильным, но сохранённый токен не имеет к нему доступа. Проверка LANDA покажет, действителен ли токен. Токен вводится только сюда и никогда не публикуется в репозитории.
Настройка: создать приватный репозиторий → создать ограниченный токен → выбрать Only select repositories и Contents: Read and write → вставить его здесь. Репозиторий должен существовать и быть private.
