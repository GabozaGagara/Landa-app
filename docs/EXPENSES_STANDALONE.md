# LANDA · Отдельный журнал «Расходы»

## Назначение

В общем меню LANDA появилась вкладка **«🧾 Расходы»**. Она намеренно изолирована от остальных модулей. У неё **свой** ключ в `localStorage`: `landa_expenses_standalone_v1`. Ни `operations`, ни финансовый `proschet`, ни касса, ни балансы поставщиков, ни накладные, ни приватный `landa-data/backup.json` при добавлении расхода **не изменяются**.

В форме доступны дата, сумма, валюта (RUB, USD, BYN, EUR), свободно вводимая категория, способ оплаты, получатель, описание и комментарий. Журнал под формой позволяет искать, фильтровать по категории, валюте и датам, редактировать и удалять записи; суммы показываются отдельно по валютам — без ошибочного суммирования рублей и долларов.

Управление: **CSV расходов** экспортирует только видимые после фильтрации записи; **Резервная копия JSON** экспортирует полный отдельный журнал; **Загрузить JSON** проверяет формат и после подтверждения заменяет только отдельный журнал. Повреждённый локальный журнал не перезаписывается автоматически. При сбое сохранения данные в памяти не считаются сохранёнными, появляется предупреждение.

## Синхронизация и резервирование

Журнал **не включён в штатную GitHub-синхронизацию** и **не включён в старую полную финансовую JSON-копию**. Это намеренное разделение по просьбе владельца «не связывать ни с каким функционалом». Поэтому на разных компьютерах эти записи изначально будут разные; переносить их можно только через JSON-экспорт/импорт. Импорт заменяет текущий набор, **не объединяет** журналы разных устройств. Пользователю нужно регулярно сохранять отдельную JSON-копию.

## Техническое исполнение

- `js/landa-expenses-core.mjs` — чистые функции ввода, дат, денежных сумм в целых копейках/центах, проверка формата, отдельные CRUD-операции, фильтрация, CSV.
- `js/landa-expenses-ui.mjs` — отдельный интерфейс и `localStorage`. Ни одного вызова `saveOps` и сохранения финансового просчёта.
- `index.html` — только вкладка, форма, журнал и подключение модуля. Старый финансовый просчёт сохранён после отмены варианта B.
- `tests/expenses.test.mjs` — синтетические тесты операций, проверок данных, валют, экспорта и изоляции.
- Тестирование: `node --test tests/expenses.test.mjs` и весь набор GitHub Actions `LANDA checks`.

Для нового раздела не требуется обновление Cloudflare Worker, только актуальная публикация GitHub Pages и обновление кэша браузера.
