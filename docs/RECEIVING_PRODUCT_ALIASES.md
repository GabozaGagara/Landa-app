# LANDA — объединение одинаковых товаров с разными названиями

## Как пользоваться

1. Откройте LANDA → **Сверка товаров** → **Сводка товаров**.
2. Нажмите **«⇄ Объединить позиции»**.
3. Отметьте две и более строки с разными названиями. Можно выбрать записи от **разных поставщиков**.
4. Введите общее название (например, **Karcher Puzzi 10/1** или **Dyson Absolute Красный**) и нажмите **«Объединить выбранные»**.
5. У объединённого товара будут общие показатели **«Заявлено», «Принято», «Разница»**, список исходных названий и поставщиков. Для отката нажмите **«Разъединить»**. Для исправления названия — **«Переименовать»**.

В **«Сводке товаров»** по умолчанию сохраняется автоматическая группировка только одинаковых наименований и артикулов *внутри одного поставщика*. Разные названия или SKU автоматически не объединяются — только по явному выбору владельца.

### Почему расчёт остаётся корректным

Каждая строка накладной сохраняется как есть. Отдельные результаты ручной сверки также остаются привязанными к исходной строке накладной. В объединённом товаре «Заявлено» суммируется по всем исходным строкам; «Принято» и «Разница» показываются **только если сверены все строки выбранной группы**. Иначе показывается «—» и доля сверенных строк.

Поиск по общему названию, старому названию или СДЭК и фильтры статуса **показывают полный товар** (все исходные строки выбранного поставщика/наборa), а не частичную сумму только подходящих строк. Отдельный фильтр по поставщику, напротив, намеренно ограничивает показатели этим поставщиком.

В режиме **«По накладным»** названия товаров остаются оригинальными. Экспорт **«Скачать CSV»** остаётся построчным. Дополнительная кнопка **«CSV объединённой сводки»** выгружает общий товар, исходные названия, поставщиков и сводные количества.

### Хранение, перенос и ограничения

Правила находятся в отдельном локальном хранилище браузера по ключу `landa_receiving_product_aliases_v1`. **Они пока не синхронизируются автоматически с GitHub и не входят в финансовый backup.json.** Для переноса между рабочими устройствами доступны:
- **«Сохранить объединения JSON»**;
- **«Загрузить объединения JSON»** (с подтверждением замены текущих правил).

Импорт не затрагивает накладные, сверку и финансы, но заменяет именно локальные правила объединения. Не рекомендуется включать в объединения товары, которые различаются по модели или комплектации. Объединения не меняют МойСклад и не отправляются поставщикам.

### Проверки

`node --test tests/receiving-aliases.test.mjs tests/landa.test.mjs`

Проверяются примеры **Puzzi 10/1** и **Dyson Absolute Красный / absolute red**, объединения разных поставщиков, отсутствие ложных «Принято», сохранение старых CSV и возможность отмены. Отдельная полная проверка GitHub Actions и проверка в реальных браузерах необходимы перед массовым использованием.

Достаточно обновить GitHub Pages / браузер через Ctrl + Shift + R. **Деплой Cloudflare Worker для этой функции не нужен**: интеграция меняет только локальную сводку и отображение.
