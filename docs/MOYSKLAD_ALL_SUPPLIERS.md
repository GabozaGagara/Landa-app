# LANDA · Приёмка «МойСклад» и фильтры накладных

## 1. Приёмка «МойСклад»: сверка всех поставщиков

В общем меню выберите **«Приёмка · МойСклад»**.

1. В поле **«Поставщик LANDA»** выберите **«Все поставщики»** (новый режим по умолчанию) либо конкретного поставщика.
2. В поле **«Статус накладных LANDA»** оставьте **«Вручены»** (безопасный режим по умолчанию) или выберите **«Все статусы»**, «Созданы», «В пути», «Готовы к выдаче».
3. Укажите даты периода **приёмок «МоегоСклада»** (серверный диапазон — до 32 дней) и нажмите **«Загрузить приёмки»**.
4. Нажмите **«Выбрать все накладные»** слева, либо отметьте нужные по одной. Справа аналогично работает **«Выбрать все приёмки»**.
5. Нажмите **«Сверить выбранное»**, изучите позиции, расхождения и выгрузите CSV при необходимости.

**Обратите внимание:** дата отправки накладной LANDA **не позднее** выбранной даты «По дату»; нижняя дата «Приёмки с» ограничивает период **приёмок «МоегоСклада»**, но не дату отправки накладной LANDA. Это позволяет учитывать накладные, отправленные раньше даты приёмки.

В общем режиме у каждой накладной отображается поставщик, а результат сравнения показывает, у каких поставщиков встречается товар. Одинаковые товары с одинаковыми нормализованными именами и артикулами суммируются в сводке, а соответствие товара «МоегоСклада» проверяется по **общему полученному количеству**, без повторного учёта одной приёмки для каждого поставщика. У разных поставщиков могут быть одинаковые ID накладных: выбор защищён парой **[поставщик, ID]**.

Ручное соответствие имени товару «МоегоСклада» для общего режима хранится отдельно от индивидуальных соответствий каждого поставщика. Неподтверждённые совпадения отмечаются отдельно, а когда разные позиции претендуют на один товар «МоегоСклада», показывается предупреждение о совместном товаре.

**Выбор «Все статусы» не означает, что товары уже получены:** это контроль сопоставления, а не фактическое подтверждение вручения. Ни статус СДЭК, ни документы и остатки «МоегоСклада» автоматически не обновляются. Старый статус `received` обрабатывается как «Вручено».

## 2. «Накладные · СДЭК»: отдельный фильтр доставки

Над таблицей накладных появился новый селектор **«Все статусы доставки / Создан / В пути / Готов к выдаче / Вручен»**. Он работает **независимо** от:
- фильтра поставщика;
- фильтра оплаты «Все оплаты / Не закрыты / Оплачены»;
- поиска по названию товара, артикулу и трек-номеру.

В таблице показывается число накладных, подходящих под выбранные фильтры. Статус «Вручен» включает историческое внутреннее значение `received`.

Фильтры не меняют накладные, балансы, оплаты или статус доставки и не требуют обновления Cloudflare Worker: всё делается в веб-интерфейсе.
