# LANDA · Приёмка смешанного паллета в СДЭК

## Как пользоваться

Открой **Сверка товаров → 🚚 Приёмка паллета**. Это третий режим рядом с «По накладным» и «Сводка товаров».

1. Нажми **«Новая приёмка»**, чтобы сохранить отдельную сессию для текущего забора товара.
2. В блоке **«Выбери накладные»** отметь галочками все отправления, которые могут оказаться в паллете. По умолчанию показываются со статусом «Готов к выдаче», можно искать по любому фрагменту номера, последним четырём цифрам или поставщику; доступен вариант «Все статусы». Выбранные накладные остаются в сессии даже после смены статуса в LANDA.
3. В блоке **«Записывай фактические места»** переключись на нужную накладную одной кнопкой **№ …1111** или через выпадающий список, напиши фактически найденный товар и число физических **мест** (обычно 1). Поле **«Штук товара»** необязательное: если в коробке 3 устройства, можно указать три штуки, но программа никогда не выводит штуки автоматически из количества мест.
4. Нажми **«Добавить в машину»**. Добавляй товары **в любом порядке**: № 1111 — первая коробка, № 2222 — коробка с другим товаром, снова № 1111 — вторая коробка.
5. Внизу автоматически формируется **итог по каждой накладной**: число записей, число мест, число различных фактических наименований, список товаров, и, когда известны, количество штук. Любую запись можно исправить или удалить. Если известен план мест по накладной, заполни **«Ожидается мест»** — появится разница мест в машине против плана. Без заданного плана программа не объявляет недостачу по числу мест.
6. Нажми **«Завершить»** после погрузки, сохрани итог **«CSV»** или полный **«Архив JSON»**. Завершённую приёмку можно посмотреть без риска случайно изменить, а при необходимости возобновить.

Номера показываются по **последним 4 цифрам**, но хранятся в записях по полному уникальному сочетанию «поставщик + ID накладной». Если четыре цифры совпали у нескольких накладных, показывается больше цифр, поставщик и, когда нужно, окончание ID.

## Подсказки по названиям и сверка состава

Под полем названия отображаются подсказки из состава выбранной накладной **и названия, введённые при прошлых приёмках**. Нажатие на подсказку заполняет поле. Это первый этап «умного ввода», не автоматическая замена текста.

После приёмки в сводке показывается:
- позиции исходной накладной, которые ещё не были записаны при загрузке;
- фактически введённые позиции без точного совпадения с составом накладной;
- число физических мест и отдельных названий.

Идентичность по названию определяется без учёта регистра и пробелов по краям; **разные написания одной модели могут отображаться как несовпадение**. Эти предупреждения — только ориентир для ручной проверки, а не автоматическое списание или признание недостачи.

Если в накладной указаны 4 штуки товара, это **не означает 4 физических места**. Количество штук проверяется отдельно только если оператор явно ввёл штуки во **всех** записях по накладной.

## Хранение и безопасность

Модуль не изменяет существующую сверку товара, счета, кассу, поставщиков, финансовые расчёты, стоимость накладных или статусы СДЭК. Приёмка хранится **локально в браузере** под отдельным ключом `landa_sdek_mixed_pallet_v1`. На других устройствах она сама не появится. Для переноса или резервной копии скачай JSON и затем загрузи его на другом устройстве; импорт **заменяет**, а не объединяет локальные сессии.

Для защиты от потерь при работе в нескольких вкладках есть проверка: если архив был изменён в другой вкладке, устаревшее окно не перезапишет его молча. Экспорт CSV включает последовательность погрузки, итоги по накладным и группировку по фактическим товарам; полные номера накладных доступны в CSV, хотя на мобильном экране показаны короткие.

**Внимание:** при очистке данных браузера локальный журнал исчезнет, если не сохранить JSON. Для синхронизации в реальном времени между несколькими телефонами потребовался бы отдельный защищённый сервер; этот режим намеренно не связан с финансовым API LANDA.

`node --test tests/pallet-intake.test.mjs` — тесты на чередование №1111/№2222/№1111, одинаковые последние четыре цифры у разных накладных, редактирование, завершение сессии, расчёт мест отдельно от единиц, подсказки и защиту данных.
