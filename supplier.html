Мои накладные и баланс

Здесь только ваши накладные и взаиморасчёты из LANDA. Статусы обновляет владелец LANDA; это не проверка сайта СДЭК в реальном времени.

Нажмите «Обновить», чтобы посмотреть актуальные данные.

1. Отправление

Для LANDA принимаются только отправления из Бреста. Текущий статус проверяется отдельно.

2. Товары

Внесите каждый товар отдельно. Цены в долларах, без пересчёта по курсу. Если цена пока неизвестна, оставьте её пустой.

Автоматическая передача в LANDA

Данные попадут сразу в приватную базу. Введите личный код поставщика, который выдал владелец LANDA. Пароль от GitHub или СДЭК не нужен.

Если прямая отправка недоступна, нажмите «Поделиться накладной» и передайте файл владельцу LANDA через мессенджер. Также можно скопировать данные или скачать JSON.
